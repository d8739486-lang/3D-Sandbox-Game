## 3. Режимы экипировки и меню предметов (Spawn Menu / Tool Gun / Руки) [ВЫПОЛНЕНО]
- [x] **Корректное определение активного оружия**:
  - Меню предметов (`B`) не пишет «[РЕЖИМ TOOL GUN]», если у игрока выбраны пустые руки (`1-1`) или пистолет (`2-1`).
  - Тулган-режим отображается исключительно тогда, когда игрок физически держит в руках Tool Gun.
  - Реализован мгновенный Fast Weapon Switch (при нажатии 1, 2... или скролле оружие сразу экипируется).
- [x] **Поведение кнопок в меню предметов**:
  - Когда взят Tool Gun: в меню отображается выбор блоков для инструмента (кнопка «Выбрать», подсветка выбранного блока `[Выбрано]`).
  - Когда Tool Gun убран (выбраны руки/оружие): кнопки возвращаются в стандартный режим «Создать» (спавн перед игроком).
  - При повторном взятии Tool Gun выбранный блок сохраняется и восстанавливается.

## 4. Мультиплеер и сетевая изоляция [ВЫПОЛНЕНО]
- [x] **Изолированные комнаты/сервера**:
  - Сервера полностью разделены по комнатам (room ID), новые игроки не спавнятся в одном общем пространстве и на главном меню.
  - Корректная обработка выхода: при нажатии «Выйти» игрок полностью отключается от P2P-комнаты, статус обновляется у всех, фантомные аватары удаляются из Three.js сцены.
- [x] **Тексты кнопок в сети**:
  - На сетевом сервере кнопка в меню паузы называется просто «Выйти», а в одиночной игре — «Сохранить и выйти».

## 5. Уведомления и чат [ВЫПОЛНЕНО]
- [x] **Уведомления в стиле игр Half-Life / Source**:
